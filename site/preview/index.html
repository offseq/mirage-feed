Integration

pfSense / OPNsense

Firewall > Aliases > Add. Type URL Table (IPs), URL https://feeds.offseq.com/mirage-feed/latest/ipv4-7d.txt, refresh 1 day. Use the alias as the source of a block rule on WAN.

FortiGate
config system external-resource
    edit "mirage-feed"
        set type address
        set resource "https://feeds.offseq.com/mirage-feed/latest/ipv4-7d.txt"
        set refresh-rate 1440
    next
end
Palo Alto (EDL)

Objects > External Dynamic Lists > Add. Type IP List, source https://feeds.offseq.com/mirage-feed/latest/ipv4-7d.txt, repeat Daily. Firewalls with a 50k EDL budget should use ipv4-top1k.txt or ipv4-top10k.txt.

MikroTik RouterOS
/tool fetch url="https://feeds.offseq.com/mirage-feed/latest/mikrotik/mirage-7d.rsc" dst-path=mirage.rsc
/import file-name=mirage.rsc

Entries carry timeout=7d, so they expire on their own.

nftables / ipset

nftables:

curl --create-dirs -fsSLo /etc/nftables.d/mirage.nft https://feeds.offseq.com/mirage-feed/latest/nft/mirage.nft
nft -f /etc/nftables.d/mirage.nft

ipset with iptables, safe to re-run:

curl -fsSL https://feeds.offseq.com/mirage-feed/latest/ipset/mirage.ipset | ipset restore
iptables -C INPUT -m set --match-set mirage4 src -j DROP 2>/dev/null \
  || iptables -I INPUT -m set --match-set mirage4 src -j DROP
ip6tables -C INPUT -m set --match-set mirage6 src -j DROP 2>/dev/null \
  || ip6tables -I INPUT -m set --match-set mirage6 src -j DROP
CrowdSec
curl -fsSL https://feeds.offseq.com/mirage-feed/latest/ipv4-7d.txt -o mirage.txt
cscli decisions import -i mirage.txt --format values --duration 48h --scope ip --reason mirage-feed
Suricata and Zeek

Suricata IP reputation: latest/suricata/categories.txt and latest/suricata/mirage-iprep.list.

alert ip any any -> $HOME_NET any (msg:"Mirage feed: known attacker"; iprep:src,MirageAttacker,>,50; sid:1900001; rev:1;)

Zeek Intel framework, with latest/zeek/mirage.intel saved locally:

redef Intel::read_files += { "/opt/mirage/mirage.intel" };
MISP, OpenCTI, Sentinel, Defender, Splunk
  • MISP: Sync Actions > Feeds > Add. Source format MISP Feed, URL https://feeds.offseq.com/mirage-feed/misp/.
  • OpenCTI: Data > Ingestion > CSV feeds on latest/attackers-ipv4-7d.csv, with the mapper in the repository under docs/opencti-csv-mapper.json. Or import latest/stix/mirage.json as a STIX bundle.
  • Microsoft Sentinel: send latest/stix/mirage.json to the STIX objects upload API, wrapped as {"sourcesystem":"OffSeq Mirage","stixobjects":[...]} with at most 100 objects per request:
    jq -c '.objects as $o | range(0; $o | length; 100) | {sourcesystem: "OffSeq Mirage", stixobjects: $o[.:. + 100]}' mirage.json
  • Defender for Endpoint: Settings > Endpoints > Indicators > Import, with latest/defender/defender-top500.csv. The import takes 500 indicators per batch, which is why the file stops at 500.
  • Splunk: add latest/attackers-7d.csv as a lookup and match on src_ip.

How an IP gets listed

An address is published only when all of these hold:

  1. It completed a TCP handshake and sent application data. UDP-only and spoofable traffic never qualifies.
  2. At least 3 Mirage sensors in at least 2 networks saw it within 7 days. One-off hits stay out.
  3. It is not a known research scanner, CDN, public resolver, bogon or any range on the MISP warninglists.
  4. Its first sighting is at least 24 hours old.

Entries expire 7 days after the last observed activity; new activity renews them. Research scanners are excluded from the blocklists and published separately in known-scanners-ipv4.txt and known-scanners-ipv6.txt, so you can allowlist them.

Before every publish, the build is rejected if the list overlaps an allowlist, contains anything wider than a /32, or changes size by more than 30% from the previous day.

Most listed addresses are compromised devices or rented infrastructure. A listing means "this address attacked honeypots", not a judgement about whoever holds it.

Verify a download

Every build ships SHA256SUMS and a minisign signature over it.

Download into the same paths as the feed, so the names match the checksum file:

curl -fsSLO https://feeds.offseq.com/mirage-feed/SHA256SUMS -O https://feeds.offseq.com/mirage-feed/SHA256SUMS.minisig
curl --create-dirs -fsSLo latest/ipv4-7d.txt https://feeds.offseq.com/mirage-feed/latest/ipv4-7d.txt
minisign -Vm SHA256SUMS -P RWQeu/vC+HeSo+5whq+ViPiKFUe35GOuuVll6WA6QKlFNirw7IzweToA
sha256sum -c --ignore-missing SHA256SUMS

On macOS, use shasum -a 256 -c in place of sha256sum -c.

Removal

If your address is listed and should not be, use the removal form or write to abuse@offseq.com. No GitHub account needed. Requests are handled within 72 hours. An address that resumes attacking is listed again.

A bug in a file format or an integration? Open an issue.
